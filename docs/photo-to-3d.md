# ReBear 照片转 3D 试验

微信开发者工具打开仓库的 wechat-app 目录。进入「开始制作」→「先用示例布料试一试」→「布料准备好，去设计小熊」→「试试照片与 3D 预览」。已添加布料时可以直接进入设计。

「已生成的样例」先显示拟真照片和各部位的布样。头部、手臂用蓝白条纹，身体、耳朵、腿部用蓝底方格。切换「3D 模型」后可拖动旋转。样例照片与 GLB 在 wechat-app/assets/photo-3d。送入模型的透明 PNG 与此说明放在一起。

「我的搭配」从拼布页读取每个部位已摆放的裁片。五个部位都有布料后，可以预览带编号的布料参考图（长按存图），复制同编号的生图提示词。将参考图和提示词交给生图工具，导入生成的照片核对，再将同一张照片交给二转三工具。把导出的 GLB 发到微信文件传输助手后，从「导入 GLB」中选取。试验中导入的文件仅在当次打开预览页时保留。更换照片会清除之前导入的模型。

样例照片使用 ImageGen，输入仓库的 sample-stripes.png 与 sample-checks.png 两张参考图。生成要求：浅蓝与米白的纵条纹只用于头和双臂；蓝底分离的米白小方格只用于躯干、双耳和双腿。鼻口为素米白、纽扣眼、缝线与棉布肌理清晰。小熊坐姿，微侧，耳手脚全部入镜，均匀柔光，透明背景，无道具和文字。

用同一张样例照片在 Apple Silicon Mac 上运行 [TripoSR](https://github.com/VAST-AI-Research/TripoSR)。用透明通道分离主体，适配 scikit-image 的 marching cubes，输出带颜色的网格。打包版将颜色烘焙到 768 × 768 的贴图，保留 40,000 个三角面，GLB 约 0.91 MiB。正面五个部位的布料类型可辨，侧面和背面可看到完整体积，但部分条纹和方格变软或变形，且遮挡面的花纹由模型推测。这条路径适合做效果预览，实际用料细节仍需人工核对。

在微信开发者工具（基础库 3.18.0）验证了从布料库进入定制页、照片与布样对照、加载 GLB、拖动旋转及切回照片。真机触摸与不同微信版本仍需测试。
