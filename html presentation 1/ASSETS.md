# ReBear AIGC 美术记录

当前 V3 使用第二版扁平手绘资源，详细提示词见 `assets/GENERATED-V2.md`。下面保留的是早期 V1 生成记录。

当前使用 `workshop-flat-v2-alpha.png`、`bear-cream-flat-v2-alpha.png`、`bear-helper-flat-v2-alpha.png`。透明版由对应生成 PNG 去除连通背景得到。`reference-pattern-demo.png` 来自用户提供的低保真交互仓库，仅作为项目纸样参考；不是 AIGC 美术或经校验的可打印纸样。

生成方式：Figma MCP `generate_image`；模型 `gpt-image-2.5-flare`。各资源为 1024 × 1024 PNG。当前环境没有通用内置 image_gen 工具，使用 Figma 设计技能提供的原生图像生成功能，未调用 CLI/API fallback。
